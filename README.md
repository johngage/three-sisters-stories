# Three Sisters Stories

A simple, colorful website for Susie (9), Betsy (7), and Natalie (5) to share their videos, books, journal entries, and drawings.

## Quick Start

```bash
# 1. Build the content
python3 build.py

# 2. Start local server
python3 -m http.server 8000

# 3. Open http://localhost:8000
```

## Adding Content

Just drop markdown files into the right folders, then run `python3 build.py`.

### Add a Journal Entry

Create a file like `content/susie/journal/2024-12-26-fun-day.md`:

```markdown
---
title: Fun Day at the Park
date: December 26, 2024
---

Today we went to the park and I played on the swings!
```

### Add a Book Review

Create a file like `content/susie/books/magic-treehouse.md`:

```markdown
---
title: Magic Tree House
author: Mary Pope Osborne
---

I love traveling through time with Jack and Annie!
```

### Add a Video

Edit `content/susie/videos.md`:

```markdown
---
title: Videos
---

- id: Numi1sVSFWk
  title: Susie's Story
  date: December 2024

- id: ANOTHER_VIDEO_ID
  title: Another Video
  date: January 2025
```

### Add a Drawing

**With emoji placeholder** - edit `content/susie/drawings.md`:

```markdown
- title: My Cat
  emoji: 🐱
```

**With actual image:**

1. Save image to `images/susie/my-cat.jpg`
2. Edit `content/susie/drawings.md`:

```markdown
- title: My Cat
  image: my-cat.jpg
```

## Workflow

1. Add/edit markdown files in `content/`
2. Run `python3 build.py`
3. Refresh browser

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/three-sisters-stories.github.io.git
git push -u origin main
```

**Important:** Run `python3 build.py` before each `git push` to update the manifest.

## File Structure

```
three-sisters-stories/
├── index.html
├── susie.html / betsy.html / natalie.html
├── build.py              ← Run this after adding content
├── css/style.css
├── js/app.js
├── content/
│   ├── manifest.json     ← Generated by build.py
│   ├── susie/
│   │   ├── videos.md
│   │   ├── drawings.md
│   │   ├── books/
│   │   │   └── *.md      ← One file per book
│   │   └── journal/
│   │       └── *.md      ← One file per entry
│   ├── betsy/
│   │   └── (same structure)
│   └── natalie/
│       └── (same structure)
└── images/
    ├── susie/
    ├── betsy/
    └── natalie/
```
